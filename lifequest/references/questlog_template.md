# Quest log template

Plain Markdown so it works in any editor (Obsidian, Ulysses, Notion import, a text file). Write headings and labels in the config's language. Leave out every section whose module is off. `{…}` = fill in.

````markdown
# Quest Log — {YYYY}-W{WW}
## "{Week theme}"

*{One or two sentences of flavour: what this week is about, in the config's genre.}*

### Character Sheet

| | |
|---|---|
| **Name** | {character} |
| **Class** | {class} |
| **Level** | {level} *(xp module)* |
| **{XP name}** | {lifetime XP} *(+{gained} last week)* *(xp module)* |
| **{Currency name}** | {spendable balance} *(xp module)* |
| **Flagship** | {project} — {this week's deliverable} *(flagship module)* |
| **Status** | {one line: what kind of week this is — travel, deadline, holiday} |

### Last week in five lines

- {energy and mood}
- {what went well, with a short quote from the journal}
- {what slipped}
- {a pattern across weeks}
- {one thing worth celebrating}

### KPI scoreboard *(kpis module)*

As of end of W{WW-1} · {n} weeks passed · pace = current / {n} × 52

| KPI | Current | Δ | Target | Pace | Status |
|---|---|---|---|---|---|
| {name} | {value} | {+x} | {target} | {pace} | 🟢 / 🟡 / 🔴 |

### Main Quest: "{name}"

*{one line: why this matters this week}*

| # | Subquest | Full | Flex |
|---|---|---|---|
| 1 | **{name}** | {task} | {smallest version} |
| 2 | **{name}** | {task} | {smallest version} |

### Daily Quests

#### Monday, {date} — "{day title}"

| Category | Quest | Full | Flex |
|---|---|---|---|
| {category 1} | **{quest name}** | {task} | {flex} |
| {category 2} | **{quest name}** | {task} | {flex} |
| … | | | |

*(repeat for Tuesday … Sunday; a short note under a day if something special happens)*

### Weekly Quests (by Sunday)

| Quest | Full | Flex |
|---|---|---|
| **{name}** | {task} | {flex} |

### {Currency name} tracker *(xp module)*

| | |
|---|---|
| Earned last week | {amount} ({breakdown}) |
| Lifetime {XP name} | {total} |
| Spendable | {balance} |
| Redeemed | {reward, cost} or — |
| Next reward in reach | {tier} at {cost} |

### Reflection — for Sunday

1. {question about a specific quest or moment}
2. {question about a pattern}
3. {question about next week}
````

## Rules

- One table per day; never merge days to save space.
- Keep quest names stable for recurring rituals; vary only the second half.
- Dates in the config's locale (e.g. "Mon 26 Oct" or "Mo, 26.10.").
- Emoji: one per category at most, or none if the player prefers.
